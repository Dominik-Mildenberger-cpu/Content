# 🍇 Vinella Content Studio

Premium Content-Management-App für vinella.de

## Start

```bash
cp .env.example .env
# API-Key in .env eintragen: ANTHROPIC_API_KEY=sk-ant-...

npm install
node server.js
```

Browser: **http://localhost:3747**

## Features

- 📅 **Kalender** – Posts planen, Tagesansicht
- 🤖 **KI Wochenplan** – komplette Woche automatisch befüllen
- 📷 **Bild-Upload** – KI analysiert und generiert Caption, Hooks, Hashtags, Higgsfield-Prompt
- 📄 **PDF-Export** – professioneller Monatsplan
- 💡 **Ideenboard** – Content-Ideen sammeln und in Posts umwandeln
- 📈 **Analytics** – Performance-Daten eintragen und auswerten
- 🤖 **KI-Chat** – unbegrenzter Content-Assistent
- ✨ **Prompt-Bibliothek** – Copy-Paste Prompts für Higgsfield, Instagram, TikTok, YouTube

## Kosten sparen

- Spar-Modus (Sidebar unten) → nutzt Claude Haiku (~$0.001/Anfrage)
- Normal-Modus → Sonnet für komplexe Aufgaben (~$0.01/Anfrage)
- Realistisch: unter $5/Monat bei normalem Einsatz
